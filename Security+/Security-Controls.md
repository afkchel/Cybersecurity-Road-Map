# Security Controls: Categories, Types, and Matrix Framework

---

## 1. Security Control Categories

Control categories define **how** a specific security mechanism is implemented within the organization.

* **Technical Controls:** Security mechanisms implemented and enforced through software, hardware, or technical systems (e.g., operating system policies, security applications).
* **Managerial Controls:** Administrative controls focused on oversight, strategic direction, and corporate documentation (e.g., official security policies, standard operating procedures).
* **Operational Controls:** Security measures executed and managed primarily by people rather than automated systems (e.g., human-led processes, security awareness training).
* **Physical Controls:** Real-world, tangible controls designed to directly restrict physical access to buildings, corporate rooms, perimeter areas, or hardware devices.

---

## 2. Security Control Types

Control types describe the specific **functional objective** of a security measure relative to an incident lifecycle.

* **Preventive:** Actively stops an unauthorized event or security breach from occurring in the first place by denying access.
* **Deterrent:** Discourages potential attackers, signaling consequences or increasing the perceived difficulty of a successful exploit.
* **Detective:** Identifies, tracks, and logs an ongoing or completed security incident, triggering alerts when anomalies occur.
* **Corrective:** Applied after an incident is detected to mitigate damage, eliminate the threat, and restore systems with minimal downtime.
* **Compensating:** Temporary or alternative measures implemented when standard controls are unavailable, unpatched, or resource-constrained.
* **Directive:** Directs human behavior toward compliant practices through explicit instructions or institutional mandates.

| **Technical** | Firewall | Splash screen | System logs | Backup recovery | Block instead of patch | File storage policies |
| **Managerial** | On-boarding policy | Demotion | Review login reports | Policies for reporting issues | Separation of duties | Compliance policies |
| **Operational** | Guard shack | Reception desk | Property patrols | Contact authorities | Require multiple security staff | Security policy training |
| **Physical** | Door lock | Warning signs | Motion detectors | Fire extinguisher | Power generator | Sign: Authorized Personnel Only |
