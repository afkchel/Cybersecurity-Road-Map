# 🌐 CompTIA Network+ Certification Prep (N10-009)

This directory serves as a central hub for my practical journey through the **CompTIA Network+** curriculum, following Professor Messer’s training course. My goal is to bridge the gap between theoretical networking concepts and hands-on implementation.

---

## 🛠️ Tech Stack & Tools
- **Network Simulation:** Cisco Packet Tracer, GNS3
- **Traffic Analysis:** Wireshark, tcpdump
- **Security & Discovery:** Nmap, Zenmap, Advanced IP Scanner
- **Platforms:** TryHackMe, Hack The Box
